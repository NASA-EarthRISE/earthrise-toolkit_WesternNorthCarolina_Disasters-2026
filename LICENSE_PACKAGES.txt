LICENSE TYPES — PLAIN ENGLISH REFERENCE
--------------------------------------------------------------------------------

  BSD-3-Clause   Free to use, modify, and redistribute. Must keep copyright
                 notice. Cannot use the author's name to endorse your product.
                 Very permissive. No copyleft.

  BSD-2-Clause   Same as BSD-3 but without the non-endorsement clause.
                 Even simpler. Fully permissive.

  MIT            One of the most permissive licenses. Use, copy, modify,
                 merge, publish, distribute freely. Just keep the copyright
                 notice. No copyleft.

  Apache-2.0     Free to use, modify, and distribute. Requires preservation
                 of copyright/license notices. Includes an explicit patent
                 grant — contributors cannot later sue you for patent
                 infringement. No copyleft.

  LGPL-3.0       Can use the library freely in your own project (including
                 proprietary). If you modify the library itself, those
                 modifications must be shared. Weaker copyleft than GPL.

  GPL-3.0        Strong copyleft. If you distribute software that includes
                 GPL code, your entire project must also be open-sourced
                 under GPL. Use with caution in mixed projects.

  MPL-2.0        Mozilla Public License. File-level copyleft. You can mix
                 MPL code with proprietary code as long as MPL files stay
                 open. More flexible than GPL.

  CC0-1.0        Public domain dedication. No restrictions whatsoever.
                 The author waives all rights.

  PSF-2.0        Python Software Foundation license. Similar to BSD/MIT.
                 Fully permissive. Used by the Python standard library.

  ISC            Very simple permissive license. Functionally equivalent
                 to MIT. Free to use and redistribute.

  Zlib           Very short permissive license. Free to use, modify, and
                 distribute. Must not misrepresent authorship.
